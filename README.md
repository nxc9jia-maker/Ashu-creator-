# Ashu Creator Website

A static, responsive multi-page website starter for the Ashu Creator Android app.

## Pages
- `index.html` — Home
- `about.html` — About the app
- `features.html` — Feature placeholders
- `screenshots.html` — Screenshot placeholders
- `download.html` — Download status (Coming Soon until a real URL is added)
- `updates.html` — Updates and release notes
- `faq.html` — Frequently asked questions
- `contact.html` — Demo form (not connected to a backend)
- `privacy.html` — Starter privacy policy template

## Preview
Open `index.html` in a browser. You can also upload the folder to a static web host.

## Before publishing
1. Replace placeholder feature descriptions with features that exist in the real app.
2. Replace screenshot placeholders with actual app screenshots.
3. Add an official Play Store or trusted download URL to `download.html` and update the disabled download button only when the link is live.
4. Connect `contact.html` to a real backend or trusted form provider. The current form does not send messages.
5. Review and customize `privacy.html` to reflect actual data practices and applicable law.
6. Add real social media links and a support contact method if you want them displayed.
7. Test navigation, form handling, page layout, and links on Android and desktop.

## Publish
Upload the contents of this folder to a static host that supports HTTPS (for example, GitHub Pages, Netlify, or Cloudflare Pages). Follow the host's current documentation to configure the project and domain. This project does not include a server or database.
